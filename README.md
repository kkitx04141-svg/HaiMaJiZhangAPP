# 黑马记账 🐴

跨平台桌面记账应用，支持 Windows 和 macOS。数据完全保存在你的电脑上，不需要联网。

---

## 这是什么

黑马记账是一个**桌面记账软件**——和微信电脑版、网易云音乐一样，安装在你的电脑上使用。

它帮你做三件事：
1. **记录**今天花了多少钱、赚了多少钱
2. **查看**这个月钱花在哪儿了（饼图、柱状图）
3. **控制**每月预算，花超了会提醒你

不需要注册账号，不需要联网，所有数据只在你自己的电脑里。

---

## 能做什么

### 📝 记一笔账
选择分类（比如"餐饮 → 午餐"）、输入金额、选日期，点保存就记录好了。支出用红色显示，收入用绿色，一眼就能分清。

内置了 **8 大类 40 小类支出**（餐饮、交通、购物……）和 **5 种收入分类**（工资、奖金、兼职……），基本覆盖日常所有场景。

### 📊 看看钱花哪儿了
统计页有两个图表：
- **饼图**：这个月你在吃、穿、住、行上各花了多少，占比一目了然
- **柱状图**：最近几个月支出和收入的对比趋势

还有一个摘要卡片，直接告诉你：本月总支出多少、总收入多少、结余多少。

### 💰 设个预算，别花超了
可以设置**每月总预算**（比如"这个月只花 5000 块"），也可以给每个分类单独设预算（比如"吃饭最多 1500"）。

首页上有个进度条，预算用了 70% 会变黄，超过 90% 会变红——提醒你该省着点了。

### 🏷️ 自定义分类
内置的分类不够用？在设置页可以自己添加、修改、删除分类，还能选 emoji 图标（🍜🚗🛒🏠……）。

### 📥 导出数据
在设置页点一下"导出 CSV"，所有记账记录就会保存成一个文件。这个文件可以用 Excel、WPS 打开，方便你做进一步分析或打印。

## 怎么安装

### 你需要准备

- 💻 电脑系统：**Windows 10 或更高版本** / **macOS 11 或更高版本**
- 📦 硬盘空间：约 200 MB
- 不需要安装任何额外软件（Node.js、Git 都不需要）

---

### 方法一：下载安装包（推荐 👍，不需要懂代码）

#### Windows 用户

1. 打开项目的 [Releases 页面](https://github.com/kkitx04141-svg/HaiMaJiZhangAPP/releases) ``
2. 找到最新版本，下载 `heima-accounting-1.0.0-setup-win.exe`
3. 双击下载的文件，按照安装向导一步步点"下一步"
4. 安装完成后，在桌面或开始菜单找到"黑马记账"图标，双击打开

> ⚠️ 如果安装时 Windows 弹出"Windows 已保护你的电脑"（SmartScreen），点击"更多信息" → "仍要运行"即可。这是因为应用没有购买代码签名证书（个人项目），不是病毒。

#### Mac 用户

1. 打开项目的 [Releases 页面](https://github.com/kkitx04141-svg/HaiMaJiZhangAPP/releases)
2. 下载 `heima-accounting-1.0.0-mac.dmg`
3. 双击 `.dmg` 文件，把"黑马记账"拖到"应用程序"文件夹
4. 在"应用程序"中找到应用，双击打开

> ⚠️ 首次打开时如果提示"无法验证开发者"，去**系统设置 → 隐私与安全性**，找到黑马记账，点击"仍要打开"。

---

### 方法二：从源码运行（适合开发者）

如果你需要修改代码或参与开发，可以用这种方式。

1. **下载项目**
   在 [GitHub 仓库](https://github.com/kkitx04141-svg/HaiMaJiZhangAPP) 点击绿色的 "Code" 按钮 → "Download ZIP"，解压到任意文件夹。

2. **安装 Node.js**（如果还没装）
   去 [nodejs.org](https://nodejs.org) 下载 LTS 版本（左侧那个），双击安装。安装完成后需要关掉终端重新打开。

3. **安装项目依赖**
   打开 VS Code → 菜单栏"终端" → "新建终端"，在终端里输入：
   ```bash
   cd 项目文件夹的路径
   npm install
   ```
   `npm install` 会下载项目需要的所有依赖文件。如果下载失败，检查代理软件是否开启。

## 怎么启动

### 如果用的是安装包

直接双击桌面图标或开始菜单里的"黑马记账"，和普通软件一样。

### 如果是从源码运行

在 VS Code 的终端中，确保当前在项目文件夹下，输入：

| 命令 | 作用 | 谁会用 |
|------|------|--------|
| `npm run dev` | 启动开发模式，边改代码边看效果 | 开发者 |
| `npm run build` | 编译检查 + 打包，确认代码没问题 | 开发者 |
| `npm run package:win` | 生成 Windows 安装程序（`.exe`） | 开发者 |
| `npm run package:mac` | 生成 Mac 安装程序（`.dmg`） | 开发者（需在 Mac 上执行） |
| `npm run test` | 运行所有自动测试 | 开发者 |

> **在哪里执行这些命令？**  
> 在 VS Code 中：顶部菜单 → 终端 → 新建终端。终端窗口会出现在 VS Code 底部，在里面输入命令后按回车执行。

`npm run dev` 执行后会持续运行，不会自动退出。Electron 应用窗口会独立弹出来。要停止的话，关闭应用窗口，或者在终端按 `Ctrl + C`。

## 文件夹说明

给想知道"每个文件夹里放了什么"的人：

```
HeiMa-JiZhangApp/
├── src/                        # 所有源代码都在这里
│   ├── main/                   # Electron 主进程——管窗口、管数据库
│   ├── renderer/               # 界面代码——你看到的所有页面和按钮
│   │   ├── components/         # 可复用的界面零件（弹窗、表单、列表……）
│   │   ├── pages/              # 三个页面：首页、统计页、设置页
│   │   ├── hooks/              # 数据获取逻辑（从数据库拉数据、刷新）
│   │   ├── db/                 # 数据库操作（增删改查写在这里）
│   │   ├── utils/              # 工具函数（金额格式化、日期处理、导出）
│   │   └── constants/          # 常量定义（内置分类列表）
│   └── preload/                # 安全桥接——界面不能直接碰数据库，必须通过这里
├── dist/                       # 打包后的安装程序（.exe / .dmg 在这里）
├── scripts/                    # 辅助脚本（如启动前清除环境变量）
├── package.json                # 项目配置文件——定义项目名、脚本、依赖
├── CLAUDE.md                   # 给 AI 开发助手看的项目说明书
└── README.md                   # 你现在正在看的文件
```

> **普通用户只需要知道**：`dist/` 文件夹里有安装包。其他文件夹是给开发者看的，不用关心。

## 常见问题

### Q1：安装时 Windows 提示"Windows 已保护你的电脑"，不让运行怎么办？

这是 Windows 的 SmartScreen 保护机制，因为应用没有购买昂贵的代码签名证书。

**解决方法**：在弹出的蓝色窗口中，点击 **"更多信息"**（可能需要往下翻），然后点击 **"仍要运行"**。应用不会损害你的电脑。

---

### Q2：Mac 上打开时提示"无法验证开发者"怎么办？

和上面的问题一样——因为个人项目没有买苹果的开发者证书。

**解决方法**：
1. 打开 **系统设置** → **隐私与安全性**
2. 往下翻，找到"已阻止使用'黑马记账'"
3. 点击 **"仍要打开"**
4. 再次双击应用图标即可

---

### Q3：启动应用后窗口是白屏或一片空白？

可能原因和解决方法：

1. **依赖没装全**：在项目文件夹的终端执行 `npm install`，等安装完再试
2. **编译出错**：看终端有没有红色报错信息（TypeScript 类型错误、找不到模块等），修复后重新 `npm run dev`
3. **ELECTRON_RUN_AS_NODE 环境变量冲突**：这个变量会导致 Electron 无法正常启动。项目自带的 `scripts/dev.js` 会自动清除它，但如果手动执行了其他命令可能出现。在终端执行 `unset ELECTRON_RUN_AS_NODE`（bash）或 `set ELECTRON_RUN_AS_NODE=`（cmd）清除它

---

### Q4：我的数据存在哪里？安全吗？

数据存在你电脑的 **用户数据目录** 下的 `heima-accounting.db` 文件中：
- Windows：`C:\Users\你的用户名\AppData\Roaming\heima-accounting\heima-accounting.db`
- Mac：`~/Library/Application Support/heima-accounting/heima-accounting.db`

.db 文件是一个 SQLite 数据库——你可以理解为"一个文件里存了你的所有记账数据"。

**安全性**：应用不联网、不上传任何数据、不收集任何信息。你的数据只在你自己的电脑上，删掉这个 .db 文件就清除所有数据了。

---

### Q5：怎么备份数据？

**方法一（推荐）**：在设置页点"导出 CSV"，所有记录会存成一个 `.csv` 文件。这个文件可以用 Excel 打开，也可以当作备份保存。

**方法二**：直接复制上面提到的 `heima-accounting.db` 文件到其他位置（U 盘、网盘等）。恢复时把它放回原位置即可。

---

### Q6：怎么卸载？

- **Windows**：打开"设置 → 应用 → 已安装的应用"，搜索"黑马记账"，点击卸载。
- **Mac**：打开"应用程序"文件夹，把"黑马记账"拖进废纸篓。

卸载不会自动删除数据文件。如果想彻底清除数据，手动删除 `heima-accounting.db` 文件（位置见 Q4）。

---

### Q7：下载依赖（npm install）特别慢或者失败？

国内网络访问 npm 仓库可能比较慢。解决方法：

1. **确保代理软件已开启**（如 Clash、V2Ray 等），代理端口通常为 10808
2. 如果不想开代理，可以改用国内镜像：
   ```bash
   npm config set registry https://registry.npmmirror.com
   ```
   然后再执行 `npm install`。执行完后如果以后想恢复默认：
   ```bash
   npm config set registry https://registry.npmjs.org
   ```

## 用什么做的

给想看技术细节的人——每项技术后面有通俗解释：

| 技术 | 干什么用的 | 普通用户需要关心吗 |
|------|-----------|-------------------|
| **Electron** | 把网页技术变成桌面应用。微信电脑版、VS Code、Discord 都是用这个做的 | 不需要 |
| **React** | 构建界面——你看到的按钮、列表、输入框、图表 | 不需要 |
| **TypeScript** | 给 JavaScript 加了"类型检查"，写代码时提前发现错误 | 不需要 |
| **Tailwind CSS** | 写样式的工具，直接在 HTML 标签上加样式，不用手写 CSS | 不需要 |
| **Recharts** | 画图表的库——统计页的饼图和柱状图就是它画的 | 不需要 |
| **sql.js** | 把 SQLite 数据库搬进浏览器运行，不需要安装数据库软件 | 不需要 |
| **Vite** | 编译打包工具——把源代码变成可以运行的程序文件 | 不需要 |
| **electron-builder** | 打包工具——把做好的应用打包成 .exe 或 .dmg 安装包 | 不需要 |

> 一句话总结：这些技术都是开发者关心的，你作为普通用户**一项都不需要理解**。

## 为什么金额用"分"而不用"元"

这是开发者关心的设计细节，但既然你可能看到代码里有 `centsToYuan` 这样的函数，解释一下原因：

计算机处理小数时会出现精度问题——比如 `0.1 + 0.2` 在计算机里不等于 `0.3`，而是 `0.30000000000000004`。这对记账软件来说是致命的（一分钱都不能错）。

解决方法：内部所有计算都用"分"（整数），比如 25.50 元就存成 2550 分。只在显示给用户看的时候，才把分转回元。这样永远不会出现小数误差。
